站点主线 ​

单细胞分析不是从 UMAP 开始的。更稳的路径是：先理解中心法则、组学层级、测序技术和免疫微环境；再学习 Scanpy、AnnData 等工具如何承载这些数据；然后深入算法论文和代码，理解模型为什么这样设计；最后通过固定目录、配置和脚本，把每一步变成可复现工作流。

1. 生物学知识从中心法则到基因组、转录组、蛋白组、代谢组、宏基因组、测序原理和免疫微环境。2. 单细胞相关工具以 AnnData, Scanpy, Seurat, and scvi-tools 为主线，逐步覆盖 CellTypist, Squidpy, scVelo 等工具。3. 算法详解逐篇阅读论文和 GitHub 代码，拆解算法作用、输入输出、模型结构、训练推理和复现要点。4. 实战模拟从公开 PBMC 数据开始，生成 processed h5ad、marker 表、UMAP 图和 QC 报告。参考资料集中收录官方教程、高质量综述、经典论文和实践型资料。

生物学知识 ​

这一部分负责回答“这些数据代表什么”。单细胞数据的每一个 cluster、marker 和通路解释，都应该能回到分子信息流、测序技术和组织微环境。

中心法则与组学层级DNA、RNA、蛋白质、代谢物和微生物群落分别回答不同层次的问题。测序方法与技术原理bulk RNA-seq、scRNA-seq、ATAC-seq、CITE-seq、空间转录组和多组学技术。常见细胞类型整理常见免疫、上皮、内皮、基质、神经和血液细胞的功能与 marker gene。免疫系统与微环境先天免疫、适应性免疫、免疫细胞谱系、肿瘤免疫微环境和组织生态位。知识总览把概念、技术和解释路径放到一套知识框架里。

单细胞相关工具 ​

工具部分负责回答“怎么把数据处理成可以解释的证据”。第一阶段围绕 AnnData, Scanpy, Seurat, and scvi-tools，把官方教程与实践经验整理成中文路径。

AnnData 教程理解 h5ad, X, obs, var, layers, raw, obsm, and uns，先把数据容器吃透。Scanpy 教程从 AnnData 到 QC、归一化、高变基因、PCA、neighbors、UMAP、Leiden 和 marker gene。Seurat 教程学习 R 生态里的 PBMC 标准流程、Seurat object、metadata、clusters 和 marker gene。scvi-tools 教程用深度生成模型处理 batch integration, latent space, differential expression, and annotation transfer。常用工具清单CellTypist, Squidpy, scVelo, Scrublet, decoupler, inferCNV, and Muon 的定位与使用场景。

算法详解 ​

这一部分负责回答“模型为什么这样工作”。之后你给我文献时，我会先读论文和补充材料，再查看官方 GitHub 仓库与关键代码路径，最后把算法拆成作用、输入输出、结构图、模块逻辑和复现要点。

板块说明说明算法详解页面的阅读标准、代码阅读流程和交付格式。Harmony拆解 batch integration 的输入输出、迭代优化、官方代码入口和结果解释。scVI理解深度生成模型如何从 raw counts 学习 latent space、归一化表达和差异表达结果。算法解读模板包含输入输出文件格式、模型结构、训练推理、代码入口和 Mermaid 示意图模板。
