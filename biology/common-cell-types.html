常见细胞类型 ​

单细胞注释的核心不是背一个 marker，而是组合证据：细胞谱系、多个 marker、组织来源、样本状态、cluster 内一致性和已知生物学功能。下面整理常见细胞类型、主要功能和常用 marker gene，作为初步注释速查表。

marker 不是单基因判决

很多 marker 会跨细胞状态或组织背景表达。例如 LYZ 可见于多种髓系细胞，EPCAM 也可能受肿瘤状态影响。注释时至少结合多个 positive markers、negative markers 和 cluster-level expression pattern。

免疫细胞 ​

T cells适应性免疫核心细胞，负责细胞毒性、辅助、调节和记忆反应。常见 marker: CD3D, CD3E, CD2, TRAC, LCK。
CD4 T cells辅助性 T 细胞，调控 B cell、髓系细胞和细胞毒反应。常见 marker: CD3D, CD4, IL7R, CCR7, LTB。
CD8 T cells细胞毒性 T 细胞，杀伤病毒感染细胞或肿瘤细胞。常见 marker: CD3D, CD8A, CD8B, GZMK, CCL5。
Cytotoxic T / NK-like T cells表达细胞毒分子，参与杀伤反应。常见 marker: NKG7, GNLY, GZMB, PRF1, CTSW。
Treg cells免疫抑制和耐受维持。常见 marker: FOXP3, IL2RA, CTLA4, TIGIT, IKZF2。
Exhausted T cells慢性抗原刺激下的功能受限状态，常见于肿瘤和慢性感染。常见 marker: PDCD1, LAG3, HAVCR2, TIGIT, TOX, CXCL13。
NK cells先天样淋巴细胞，识别应激或低 MHC 细胞并执行杀伤。常见 marker: NKG7, GNLY, KLRD1, FCGR3A, PRF1。
B cells抗体产生前体、抗原呈递和体液免疫。常见 marker: MS4A1, CD79A, CD79B, BANK1, CD74。
Plasma cells分泌抗体的终末分化 B 细胞。常见 marker: MZB1, XBP1, SDC1, JCHAIN, IGKC, IGHG1。
Monocytes循环髓系细胞，可迁入组织并参与炎症或分化为巨噬细胞。常见 marker: LYZ, S100A8, S100A9, FCN1, LST1。
Macrophages组织驻留或募集的吞噬细胞，参与清除、修复、抗原呈递和炎症调控。常见 marker: C1QA, C1QB, C1QC, APOE, CD68, MARCO。
Dendritic cells抗原呈递和 T cell priming。常见 marker: FCER1A, CLEC10A, CD1C, CST3, LILRA4, IRF8。
Neutrophils急性炎症和抗菌反应中的粒细胞。常见 marker: S100A8, S100A9, FCGR3B, CSF3R, CXCR2。
Mast cells过敏、屏障免疫和组织炎症。常见 marker: TPSAB1, TPSB2, CPA3, KIT, MS4A2。

上皮、内皮和基质细胞 ​

Epithelial cells覆盖组织表面或腺体结构，承担屏障、分泌和吸收功能。常见 marker: EPCAM, KRT8, KRT18, KRT19, CDH1。
Basal cells上皮干/祖细胞样群体，参与组织更新。常见 marker: KRT5, KRT14, TP63, KRT15。
Ciliated epithelial cells纤毛运动和黏液清除，常见于呼吸道和生殖道。常见 marker: FOXJ1, PIFO, TPPP3, CAPS, DNAH5。
Secretory / Goblet cells分泌黏液或屏障相关蛋白。常见 marker: MUC5AC, MUC5B, TFF3, AGR2, SPDEF。
Endothelial cells血管内皮，参与屏障、血管生成、凝血和免疫细胞迁移。常见 marker: PECAM1, VWF, KDR, EMCN, CDH5。
Lymphatic endothelial cells淋巴管内皮，参与组织液回流和免疫细胞运输。常见 marker: PROX1, LYVE1, PDPN, FLT4, CCL21。
Fibroblasts产生细胞外基质、参与修复、纤维化和微环境塑形。常见 marker: COL1A1, COL1A2, DCN, LUM, COL3A1。
Myofibroblasts收缩性和 ECM 重塑更强的 fibroblast 状态。常见 marker: ACTA2, TAGLN, MYL9, COL1A1, POSTN。
Pericytes包绕微血管，调节血管稳定性和屏障功能。常见 marker: RGS5, PDGFRB, CSPG4, MCAM, NOTCH3。
Smooth muscle cells血管或器官壁平滑肌收缩。常见 marker: ACTA2, MYH11, TAGLN, CNN1, TPM2。

神经系统相关细胞 ​

Neurons神经信号传递。常见 marker: SNAP25, RBFOX3, SYT1, TUBB3, MAP2。
Excitatory neurons谷氨酸能兴奋性神经元。常见 marker: SLC17A7, SLC17A6, CAMK2A, SATB2。
Inhibitory neuronsGABA 能抑制性神经元。常见 marker: GAD1, GAD2, SLC6A1, DLX1, DLX2。
Astrocytes支持神经元、调节代谢和突触环境。常见 marker: GFAP, AQP4, ALDH1L1, SLC1A3。
Oligodendrocytes形成中枢神经系统髓鞘。常见 marker: MBP, MOG, PLP1, MAG, MOBP。
Microglia中枢神经系统驻留免疫细胞。常见 marker: P2RY12, CX3CR1, TMEM119, AIF1, C1QA。

血液和其他常见细胞 ​

Erythroid cells红系细胞，负责血红蛋白表达和氧运输。常见 marker: HBB, HBA1, HBA2, ALAS2, GYPA。
Megakaryocytes / Platelets血小板生成和凝血相关。常见 marker: PPBP, PF4, GP9, ITGA2B, NRGN。
Hematopoietic stem/progenitor cells造血干/祖细胞，具备分化潜能。常见 marker: CD34, SPINK2, PROM1, AVP, GATA2。
Adipocytes脂质储存和内分泌调节。常见 marker: ADIPOQ, FABP4, PLIN1, LPL, LEP。
Hepatocytes肝脏代谢、解毒和血浆蛋白合成。常见 marker: ALB, APOA1, TTR, CYP3A4, FGB。
Proliferating cells细胞周期活跃状态，不一定是独立细胞类型。常见 marker: MKI67, TOP2A, STMN1, PCNA, CENPF。

注释时的检查顺序 ​

先看大谱系 marker再看亚群 marker检查 negative markers查看 cluster 内一致性结合样本来源排查 doublet回看 QC 指标保留 ambiguous 标签

常见误区 ​

  1. 只用一个 marker 命名细胞。
  2. 把 proliferating、stress、interferon response 这类状态误当成细胞类型。
  3. 忽略组织特异性，例如 fibroblast、macrophage 和 endothelial cell 在不同组织中 marker 差异明显。
  4. 忽略肿瘤细胞的异常表达，尤其是 epithelial marker、MHC、cell cycle 和 CNV 相关信号。
  5. 没有检查 doublet，导致 T cell + myeloid 或 epithelial + immune 混合 cluster 被误注释。
