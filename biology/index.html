生物学知识 ​

这一部分先按“分子信息流 -> 多组学层级 -> 测序技术 -> 细胞类型 -> 免疫学机制 -> 组织微环境”的顺序组织。单细胞分析的难点不只是跑工具，而是把 cluster、marker、pathway、cell state 和疾病机制放回生物学框架里解释。

中心法则与组学层级从 DNA、RNA、蛋白质到代谢物，再扩展到微生物群落和多组学整合。测序方法与技术原理理解不同测序方法的读出对象、实验偏倚和适合回答的问题。常见细胞类型按细胞谱系整理功能、典型 marker 和注释时的常见注意事项。免疫系统与微环境免疫细胞谱系、先天/适应性免疫、肿瘤和组织微环境解释框架。Janeway 免疫学学习图谱把《詹韦免疫生物学》的五大部分重组为适合单细胞研究的免疫学路线。固有免疫屏障、补体、模式识别、炎症、干扰素、NK 细胞和固有淋巴样细胞。抗原识别与抗原提呈BCR、TCR、MHC、抗原加工、交叉提呈和非经典抗原识别。淋巴细胞发育与活化V(D)J 重排、B/T 细胞选择、TCR/BCR 信号、共刺激和共抑制。适应性免疫应答T cell priming、CD4/CD8 效应分化、B cell 生发中心、抗体功能和免疫记忆。黏膜免疫、疾病与治疗黏膜屏障、微生物群、免疫缺陷、过敏、自身免疫、移植、疫苗和肿瘤免疫治疗。参考资料收集本部分引用的经典论文、高质量综述和官方资源。

阅读方式 ​

先问分子层级再问测量技术接着看细胞类型再看免疫识别理解效应应答最后回到组织生态位
为什么先放文献背书
