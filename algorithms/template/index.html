这个页面是模板。收到具体文献后，我会复制这一结构，为每个算法生成独立页面。

2. 算法作用 ​

需要讲清楚：

  1. 它解决什么生物学或计算问题。
  2. 它输入什么数据，输出什么结果。
  3. 它相对已有方法的改进点是什么。
  4. 它不适合什么场景。
判断标准

不能只复述摘要。需要能用自己的话解释：如果我是用户，为什么要用这个算法，而不是 Scanpy/Seurat/scVI/CellTypist/CellChat 等已有工具。

3. 输入与输出 ​

输入文件 ​

输入格式形状/字段必需说明
表达矩阵.h5ad, .mtx, .csv, .tsv细胞 × 基因是例如原始计数或对数归一化矩阵
元数据.csv, .tsv, adata.obs细胞 × 协变量视方法而定样本、批次、条件、细胞类型
基因元数据.csv, .tsv, adata.var基因 × 注释视方法而定基因符号、基因 ID、染色体
图或空间坐标.h5ad, .csv细胞/点位 × 坐标视方法而定空间模型或图模型需要

输出文件 ​

输出格式形状/字段用途
潜在表示.npy, .csv, adata.obsm细胞 × 潜空间维度下游邻居图/UMAP/聚类
预测标签.csv, adata.obs细胞 × 标签注释/分类
分数/概率.csv, .h5ad细胞 × 类别置信度/不确定性
训练后的模型.pt, .pkl, checkpoint 目录模型权重复用/推理

5. 模型结构详解 ​

这一节要参考论文模型图和代码实现，逐层拆解：

数据编码器输入矩阵如何进入模型？是否使用计数分布、对数归一化表达、图结构或 token？
核心模块核心结构是什么？VAE、GNN、Transformer、对比学习、扩散模型还是概率模型？
解码器 / 任务头输出如何生成？重构表达、分类标签、连接分数、RNA 速率还是扰动响应？
损失函数训练目标包括哪些项？重构、KL、对比学习、分类、图正则化还是对抗损失？

6. 训练与推理流程 ​

训练 ​

text
读取数据 -> 预处理 -> 构建数据集 -> 初始化模型 -> 训练循环 -> 验证 -> 保存 checkpoint

需要记录：

  1. 批大小、训练轮数、优化器、学习率。
  2. 是否使用 GPU。
  3. 是否需要负采样或图构建。
  4. 随机种子和版本依赖。

推理 ​

text
读取 checkpoint -> 读取查询数据 -> 对齐基因/特征 -> 运行推理 -> 导出结果

需要特别检查查询数据是否和训练/参考数据的基因空间、归一化方式和元数据一致。

python train.py --config configs/example.yaml
python predict.py --checkpoint outputs/model.pt --query data/query.h5ad

9. 结果解释 ​

需要回答：

  1. 输出结果应该如何读。
  2. 哪些图或指标用于验证算法是否正常。
  3. 哪些结果容易过度解释。
  4. 与传统方法或基线方法如何比较。

10. 常见问题与风险 ​

输入格式不匹配基因顺序、基因 ID、条形码、元数据、归一化方式不一致会让结果失真。
论文图和代码不完全一致需要以实际仓库代码为准，并标注论文描述与实现差异。
默认参数不可泛化示例数据参数不一定适合真实队列、跨平台数据或大规模图谱。
评估指标单一需要同时看生物学保留、批次混合、准确率、校准情况和运行时间。
