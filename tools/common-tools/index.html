常用单细胞分析工具清单 ​

除 AnnData, Scanpy, Seurat, and scvi-tools 之外，单细胞项目常会按任务接入专用工具。下面按分析问题组织一版工具地图，方便决定下一步该学什么。

细胞类型注释 ​

CellTypistPython 自动注释工具，适合 immune cell annotation transfer。输出需要 marker gene 和组织背景复核。
SingleRR/Bioconductor 注释工具，基于 reference transcriptome 做 label transfer。
AzimuthSeurat 生态 reference mapping 工具，适合有高质量 reference atlas 的场景。
Garnett / scmap可用于 marker-based 或 reference-based annotation，适合和其它结果交叉验证。

空间组学 ​

Squidpyscverse 空间分析工具，覆盖 spatial graph, neighborhood enrichment, image features, and ligand-receptor。
Giotto空间转录组综合分析框架，常用于空间可视化、空间模式和细胞互作分析。
Seurat spatialSeurat 生态中的 Visium/空间分析流程，适合 R 用户。
stLearn空间转录组分析工具，强调组织图像、空间邻域和细胞通讯。

细胞通讯与微环境 ​

CellChatR 工具，用 ligand-receptor database 推断细胞群间通讯网络，适合微环境和免疫互作分析。
CellPhoneDB常用 ligand-receptor 推断工具，适合 cluster-level communication screening。
NicheNet把 ligand activity 和 target gene program 连接起来，适合问“哪个发送细胞可能驱动接收细胞状态”。
LIANA整合多种 cell-cell communication 方法的框架，适合比较不同算法输出。
通讯推断不是功能验证

CellChat, CellPhoneDB, and NicheNet 的结果通常是候选互作。更可靠的解释需要空间邻近、配体/受体表达、下游 target program 和实验验证共同支持。

轨迹、发育和 RNA velocity ​

Monocle 3R 生态轨迹推断工具，常用于 pseudotime, trajectory graph, and branch analysis。
Slingshot基于 cluster 和低维空间的 lineage inference 工具，适合较清晰的分化路径。
Palantir用于连续状态、分化潜能和 fate probability 的轨迹分析。
scVeloRNA velocity 工具，用 spliced/unspliced counts 推断动态方向，依赖较强模型假设。

批次整合与大数据处理 ​

Harmony常用 batch correction/integration 工具，可接 Seurat 或 Scanpy。
BBKNNScanpy 生态批次平衡邻居图方法，适合快速 integration baseline。
LIGER矩阵分解式整合方法，适合跨数据集和跨模态分析。
scArches基于 scvi-tools 的 reference mapping/atlas update 框架。

Doublet、质量控制和环境 RNA ​

ScrubletPython doublet 检测工具，常与 Scanpy 搭配。
DoubletFinderSeurat/R 生态常用 doublet 检测工具。
scDblFinderBioconductor doublet detection 工具，适合 R pipeline。
SoupX / CellBender处理 ambient RNA 或 background contamination。使用前要理解平台和样本背景。

CNV、肿瘤克隆和恶性细胞识别 ​

inferCNV从表达矩阵推断 large-scale CNV，常用于 malignant vs non-malignant 区分。
CopyKAT自动识别 aneuploid tumor cells 和 diploid normal cells 的 R 工具。
HoneyBADGER从 scRNA-seq 推断 CNV 和 LOH 的工具。
CONICSmat基于表达矩阵识别 CNV 相关模式，适合肿瘤单细胞场景。

通路、转录因子和功能活性 ​

decouplerPython/R 工具，用 regulator-target 或 pathway-gene sets 推断 TF/pathway activity。
AUCell / SCENIC推断 regulon activity，适合转录因子调控网络分析。
GSVA / ssGSEA常用于 pathway score，但单细胞场景要注意 dropout 和 composition bias。
PROGENy / DoRothEA常与 decoupler 搭配，用于 pathway 和 TF activity 推断。

多组学与模态整合 ​

Muon / MuDatascverse 多模态容器和分析工具，适合 RNA + ATAC, RNA + protein 等数据。
TOTALVIscvi-tools 中处理 CITE-seq RNA + protein 的模型。
MULTIVIscvi-tools 中处理 paired/unpaired multiome 的模型。
SignacSeurat 生态的 scATAC-seq 和 multiome 分析工具。

差异表达和组成变化 ​

MAST单细胞差异表达常用模型，适合考虑 detection rate 等因素。
edgeR / DESeq2 pseudobulk按 sample 聚合做 pseudobulk DE，通常比 cell-level DE 更贴近实验设计。
Milo分析细胞状态/邻域 abundance changes，适合 differential abundance。
muscat多样本多群体单细胞差异状态分析工具。

选择原则 ​

  1. 先明确任务：annotation, integration, velocity, spatial, communication, pathway, CNV, multiome, DE, or abundance。
  2. 优先看官方教程，确认输入对象、矩阵要求和版本。
  3. 博客和经验帖适合补参数判断，但不能替代官方 API。
  4. 自动工具的输出要回到 marker、样本设计和生物学背景复核。
  5. 涉及微环境和通讯时，最好结合空间邻近或实验验证。
